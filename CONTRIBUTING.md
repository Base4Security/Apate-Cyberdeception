# Contributing to Apate

Apate is the open-source community edition under AGPL-3.0-or-later. Bug reports, reproducible usability problems, and documentation suggestions are welcome through GitHub issues. For a security vulnerability, follow [SECURITY.md](SECURITY.md) and do not open a public issue.

Code pull requests are temporarily closed while the project owner finalizes its contributor agreement and commercial relicensing policy. Please do not submit code expecting it to be merged before those terms are published and reviewed. This does not affect your ability to use, study, modify, or fork the AGPL edition.

When code contributions reopen, changes should be scoped, include appropriate tests, and follow the repository conventions: Spanish comments and docstrings, minimal dependencies, deterministic deployment decisions, and explicit operator approval for suggestions. Run `python -m pytest` before opening a pull request.
